To use the program, the following steps need to be followed:

1. Download the Kaggle insurance3r2.csv file and rename it as insurance.csv.
2. Upload the file to the Jupyter Notebook homepage.
3. Execute all the code lines present in the notebook.
4. Test the model by inputting the following code (following the value format of the dataset):
	new_data = [[<age>, <sex>, <BMI>, <steps>, <children>, <smoker>, <region>, <charges>]]
	prediction = insurance_classifier.predict(new_data)
	print(prediction)

Note that all the input values should be numeric.
